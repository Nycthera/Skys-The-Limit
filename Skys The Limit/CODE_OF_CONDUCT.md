# Contributor Covenant Code of Conduct

Our code of conduct outlines expectations for participation. We value respectful, inclusive, and constructive communication.

Standards
- Be kind and welcoming.
- Be respectful of differing viewpoints and experiences.
- Be collaborative and responsive to feedback.

Reporting
If you experience or witness unacceptable behavior, please contact the project maintainers at `your-email@domain.com`. All reports will be treated confidentially.

For the full text, see: https://www.contributor-covenant.org/version/2/0/code_of_conduct/
