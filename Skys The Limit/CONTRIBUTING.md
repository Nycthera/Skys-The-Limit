# Contributing to Skys The Limit

Thanks for your interest in contributing! We appreciate any help improving the app — whether it's bug fixes, documentation, or new features.

Guidelines
- Fork the repository and create a topic branch for your change.
- Keep changes focused and small; open multiple PRs for unrelated work.
- Follow the existing Swift style. We recommend running `swiftlint` and `swiftformat` before submitting.
- Write clear commit messages and include a short description in your PR.

How to Submit
1. Fork the repository.
2. Create a branch: `git checkout -b feature/short-description`.
3. Make your changes and run linters/formatters.
4. Push and open a Pull Request against `main`.

Reporting Issues
- Use the issue templates when opening bugs or feature requests.

Code review
- Expect constructive feedback. Be responsive to requested changes.

Thank you for helping to improve Skys The Limit!
